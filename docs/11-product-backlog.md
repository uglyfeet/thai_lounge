# Product Backlog

## Purpose

This backlog lists the main tasks required to complete The Thai Lounge website. Tasks will be completed in a practical order, with mandatory assessment requirements taking priority.

## Development Tasks

### 1. Project Setup
- [x] Create the Django project and bookings app.
- [x] Set up the virtual environment and dependencies.
- [x] Create the GitHub repository.
- [ ] Organise the Django apps and project settings.

### 2. Database and Treatments
- [ ] Design and create the database models.
- [ ] Add treatment names, descriptions, durations and prices.
- [ ] Display treatments on the website.
- [ ] Test model relationships and validation.

### 3. Customer Accounts
- [ ] Implement registration, login and logout.
- [ ] Protect customer-only pages.
- [ ] Ensure customers can only access their own bookings.

### 4. Appointment Booking
- [ ] Display available appointment dates and times.
- [ ] Allow customers to request appointments.
- [ ] Validate booking details.
- [ ] Prevent conflicting appointments.
- [ ] Allow customers to view and manage their bookings.

### 5. Payments
- [ ] Integrate Stripe Checkout in test mode.
- [ ] Record payment status against bookings.
- [ ] Handle successful, failed and cancelled payments.
- [ ] Test payment processing without using real payments.

### 6. Owner Management
- [ ] Allow the owner to manage treatments.
- [ ] Allow the owner to manage availability and bookings.
- [ ] Protect management functions from unauthorised access.

### 7. User Interface
- [ ] Create a consistent responsive layout.
- [ ] Add navigation, forms and validation messages.
- [ ] Test the website on desktop and mobile screen sizes.

### 8. Testing and Deployment
- [ ] Complete manual and automated testing.
- [ ] Correct significant defects.
- [ ] Deploy the website.
- [ ] Test the deployed website.
- [ ] Complete the README and final project documentation.

## Backlog Status

The backlog will be updated as tasks are completed. The priority is to meet the mandatory assessment requirements and deliver a working, tested website.

## Future Enhancements

These features are outside the initial MS4 scope unless required by the assessment brief.

- Allow customers to select a preferred massage therapist when booking.
- Store staff details and manage individual staff availability.
- Display appointment times based on the selected therapist's availability.
- Prevent bookings that conflict with a therapist's existing appointments.
