# Project Vision — The Thai Lounge

## Project Overview

The Thai Lounge is a full-stack web application being developed for a Thai massage business. The website will allow customers to view treatments, check appointment availability, create an account and book treatments online.

## Project Purpose

The purpose of the project is to provide a convenient online booking system for customers and reduce the time the business owner spends managing appointments manually.

## Target Users

- **Customers:** People who want to browse treatments, view prices and durations, register an account and book appointments online.
- **Business owner:** The owner of The Thai Lounge, who needs to manage treatments, prices, availability and customer bookings.

## Main Features

- Display treatments with descriptions, prices and durations.
- Customer registration, login and logout.
- Appointment booking with date and time validation.
- View and manage customer bookings.
- Allow the business owner to manage treatments and bookings.
- Accept online payments using Stripe test mode.
- Provide clear confirmation and error messages.

## Technologies

- HTML and CSS for page structure and styling.
- JavaScript for client-side interactivity.
- Python and Django for application logic.
- A relational database for storing application data.
- Stripe for online payment processing.

## Project Goal

Deliver a functional, secure, responsive and tested website that meets the mandatory MS4 assessment requirements and provides a useful booking service for The Thai Lounge.
