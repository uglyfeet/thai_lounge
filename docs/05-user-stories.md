# User Stories — The Thai Lounge

## Customer User Stories

**US1 — Browse treatments**

As a customer, I want to view available massage treatments, so that I can choose a suitable treatment.

**US2 — View treatment details**

As a customer, I want to see treatment descriptions, prices and durations, so that I can make an informed choice.

**US3 — Create an account**

As a customer, I want to register and log in securely, so that I can manage my bookings.

**US4 — Book an appointment**

As a customer, I want to select a treatment, date and available time, so that I can arrange an appointment.

**US5 — Avoid booking conflicts**

As a customer, I want unavailable appointment times to be excluded, so that I do not book an appointment that conflicts with another booking.

**US6 — Manage my bookings**

As a customer, I want to view and cancel my bookings, so that I can manage my appointments.

**US7 — Pay online**

As a customer, I want to pay securely through Stripe, so that I can complete the payment for my booking.

**US8 — Receive confirmation**

As a customer, I want clear booking and payment confirmation, so that I know the outcome of my appointment request and payment.

## Business Owner User Stories

**US9 — Manage treatments**

As the business owner, I want to add, edit and remove treatments, so that the website displays current information.

**US10 — Manage availability**

As the business owner, I want to manage available appointment times, so that customers can book suitable appointments.

**US11 — Manage bookings**

As the business owner, I want to view and update bookings, so that I can manage the appointment schedule.

**US12 — Check payments**

As the business owner, I want to view payment statuses, so that I can identify successful and unsuccessful payments.

## Acceptance

Each user story will be tested against its intended outcome. Security, validation and access permissions will also be tested where relevant.
