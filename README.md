# The Thai Lounge

## Project Overview

The Thai Lounge is a full-stack Django website for a Thai massage business. It will allow customers to view treatments, create accounts, book appointments and pay online using Stripe.

The website will also provide management features for the business owner to manage treatments, availability and bookings.

## Project Goals

- Display treatments, prices and durations.
- Allow customers to register and log in.
- Enable customers to book and manage appointments.
- Prevent conflicting bookings.
- Integrate Stripe for online payments.
- Provide secure management features for the business owner.
- Deliver a responsive, tested website.

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Django
- Relational database
- Stripe
